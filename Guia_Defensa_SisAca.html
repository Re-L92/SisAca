🏛️ 1. Arquitectura en 4 Capas y Flujo de Comunicación
🎙️ Lo que le dices al profesor para iniciar:
"Profesor, nuestro sistema no es un monolito desordenado. Está construido bajo la arquitectura profesional de 4 Capas Desacopladas (N-Tier). Cada capa tiene una única responsabilidad:
1) UI: Presenta los datos y captura los eventos del usuario.
2) BLL: Contiene todas las reglas de negocio institucionales y cálculos.
3) DAL: Conecta a SQL Server sin escribir consultas SQL en C#, usando solo Stored Procedures.
4) Entidades: Estructuras fuertemente tipadas que viajan entre todas las capas."
1. El Usuario hace clic en UI (FrmGestionMatricula):
El formulario captura el evento (ejemplo: escribir en el buscador o presionar "Matricular") y llama a la clase _matriculaBll.
2. La Capa BLL (MatriculaBll) toma el control:
Evalúa las reglas: ¿El estudiante está Inactivo? ¿Ya fue promovido? ¿Cuántas materias reprobó? Si todo es válido, llama a la clase _matriculaDal.
3. La Capa DAL (MatriculaDal) abre la conexión:
Crea el objeto SqlConnection, configura SqlCommand con CommandType.StoredProcedure, envía los parámetros tipados y ejecuta la consulta.
4. SQL Server ejecuta el Procedimiento Almacenado:
La base de datos ejecuta el SP dentro de una transacción segura (ACID), aplica bloqueos de cupos y devuelve el resultado. El DAL lo convierte a objetos y la UI lo muestra en pantalla.

En la base de datos se implementaron tablas en 3ra Forma Normal (3FN), índices filtrados y Stored Procedures transaccionales. Aquí está el código exacto:

SQL Server — SP_ListarMatriculas (Evita duplicados al pasar de año) 
CREATE OR ALTER PROCEDURE dbo.SP_ListarMatriculas
    @IdAnio INT = 0,
    @IdSeccion INT = 0,
    @Filtro NVARCHAR(100) = ''
AS
BEGIN
    SET NOCOUNT ON;

    -- CTE que numera las matrículas de cada alumno por fecha descendente
    WITH UltimaMatricula AS (
        SELECT 
            m.IdMatricula,
            m.IdEstudiante,
            m.IdAnio,
            m.IdSeccion,
            m.FechaMatricula,
            m.EstadoMatricula,
            ROW_NUMBER() OVER (PARTITION BY m.IdEstudiante ORDER BY m.IdMatricula DESC) AS Fila
        FROM dbo.Matricula m
        WHERE m.EstadoMatricula <> 'Cancelado'
    )
    SELECT 
        um.IdMatricula,
        e.IdEstudiante,
        e.CodigoEstudiante,
        CONCAT(e.Nombres, ' ', e.Apellidos) AS NombreEstudiante,
        e.Estado AS EstadoEstudiante, -- <-- Devuelve si está Activo o Inactivo
        an.IdAnio,
        an.NombreAnio,
        an.Ciclo,
        sec.IdSeccion,
        sec.NombreSeccion,
        um.FechaMatricula,
        um.EstadoMatricula,
        ISNULL(CONCAT(doc.Nombres, ' ', doc.Apellidos), 'Sin Docente Guía') AS DocenteGuia,
        ISNULL(aus.Aula, 'Por Asignar') AS Aula
    FROM UltimaMatricula um
    INNER JOIN dbo.Estudiante e ON um.IdEstudiante = e.IdEstudiante
    INNER JOIN dbo.AnioAcademico an ON um.IdAnio = an.IdAnio
    INNER JOIN dbo.Seccion sec ON um.IdSeccion = sec.IdSeccion
    LEFT JOIN dbo.Aula_Seccion aus ON aus.IdAnio = um.IdAnio AND aus.IdSeccion = um.IdSeccion
    LEFT JOIN dbo.Docente doc ON aus.IdDocenteGuia = doc.IdDocente
    WHERE um.Fila = 1 -- <-- ¡ESTA LÍNEA ELIMINA EL ERROR DE APARECER EN DOS AÑOS!
      AND (@IdAnio = 0 OR um.IdAnio = @IdAnio)
      AND (@IdSeccion = 0 OR um.IdSeccion = @IdSeccion)
      AND (@Filtro = '' 
           OR e.CodigoEstudiante LIKE '%' + @Filtro + '%'
           OR e.Nombres LIKE '%' + @Filtro + '%'
           OR e.Apellidos LIKE '%' + @Filtro + '%')
    ORDER BY um.IdMatricula DESC;
END;
🔍 Explicación profunda de SP_ListarMatriculas:
  • ¿Por qué el alumno aparecía en 7mo y 8vo a la vez? Porque en la tabla Matricula quedaba el registro del año viejo y se creaba el registro del año nuevo. Al hacer un SELECT normal, traía ambos.
  • ¿Cómo se resolvió? Con la función de ventana ROW_NUMBER() OVER (PARTITION BY m.IdEstudiante ORDER BY m.IdMatricula DESC). A la matrícula más nueva le pone Fila = 1 y a la anterior Fila = 2. Al poner WHERE um.Fila = 1, únicamente se muestra el año que está cursando actualmente.
SQL Server — SP_MatricularSiguienteAnio (Transaccional) 
CREATE OR ALTER PROCEDURE dbo.SP_MatricularSiguienteAnio
    @IdMatriculaActual INT,
    @IdSeccionNueva INT,
    @NuevoIdMatricula INT OUTPUT,
    @MensajeResultado NVARCHAR(200) OUTPUT
AS
BEGIN
    SET NOCOUNT ON;
    BEGIN TRANSACTION; -- <-- Transacción ACID
    BEGIN TRY
        DECLARE @IdEstudiante INT, @IdAnioActual INT, @NombreAnioActual NVARCHAR(50), @EstadoMatriculaActual NVARCHAR(30);

        SELECT @IdEstudiante = m.IdEstudiante, @IdAnioActual = m.IdAnio, 
               @NombreAnioActual = a.NombreAnio, @EstadoMatriculaActual = m.EstadoMatricula
        FROM dbo.Matricula m INNER JOIN dbo.AnioAcademico a ON m.IdAnio = a.IdAnio
        WHERE m.IdMatricula = @IdMatriculaActual;

        -- 1. Validar que no haya sido ya aprobado o reprobado
        IF @EstadoMatriculaActual IN ('Promovido', 'Estudiante Graduado')
            RAISERROR('El estudiante ya ha sido promovido anteriormente.', 16, 1);

        -- 2. Caso especial: Alumno de 11mo Grado (5to Año) -> Graduación
        IF @NombreAnioActual = '11mo Grado' OR @IdAnioActual = 5
        BEGIN
            UPDATE dbo.Matricula SET EstadoMatricula = 'Estudiante Graduado' WHERE IdMatricula = @IdMatriculaActual;
            UPDATE dbo.Estudiante SET Estado = 'Estudiante Graduado' WHERE IdEstudiante = @IdEstudiante;
            SET @NuevoIdMatricula = @IdMatriculaActual;
            SET @MensajeResultado = '¡Felicidades, estudiante graduado!';
            COMMIT TRANSACTION;
            RETURN;
        END

        -- 3. Calcular el año consecutivo siguiente
        DECLARE @IdAnioNuevo INT = @IdAnioActual + 1;
        DECLARE @NombreAnioNuevo NVARCHAR(50) = (SELECT NombreAnio FROM dbo.AnioAcademico WHERE IdAnio = @IdAnioNuevo);

        -- 4. Validar límite de cupo en la sección (< 40)
        DECLARE @CuposOcupados INT = (SELECT COUNT(1) FROM dbo.Matricula WHERE IdAnio = @IdAnioNuevo AND IdSeccion = @IdSeccionNueva AND EstadoMatricula = 'Activo');
        IF @CuposOcupados >= 40
            RAISERROR('La sección ha alcanzado su cupo máximo de 40 estudiantes.', 16, 1);

        -- 5. Cambiar estado anterior a 'Promovido'
        UPDATE dbo.Matricula SET EstadoMatricula = 'Promovido' WHERE IdMatricula = @IdMatriculaActual;

        -- 6. Insertar nueva matrícula activa
        INSERT INTO dbo.Matricula (IdEstudiante, IdAnio, IdSeccion, FechaMatricula, EstadoMatricula)
        VALUES (@IdEstudiante, @IdAnioNuevo, @IdSeccionNueva, GETDATE(), 'Activo');
        SET @NuevoIdMatricula = SCOPE_IDENTITY();

        -- 7. Precarga automática de la malla de asignaturas para el nuevo grado
        INSERT INTO dbo.Calificacion (IdMatricula, IdAsignatura, EstadoAsignatura, Observacion)
        SELECT @NuevoIdMatricula, ga.IdAsignatura, 'En proceso', 'Inscripción de nuevo año académico'
        FROM dbo.Grado_Asignatura ga WHERE ga.IdAnio = @IdAnioNuevo;

        SET @MensajeResultado = CONCAT('¡Estudiante promovido exitosamente en ', @NombreAnioNuevo, '!');
        COMMIT TRANSACTION;
    END TRY
    BEGIN CATCH
        ROLLBACK TRANSACTION; -- Si algo falla, revierte todo para no dejar datos corruptos
        THROW;
    END CATCH
END;

C# — MatriculaDal.cs (ListarMatriculasAsync) 
public async Task<List<MatriculaEntity>> ListarMatriculasAsync(int idAnio = 0, int idSeccion = 0, string filtro = "")
{
    var lista = new List<MatriculaEntity>();

    using SqlConnection cn = Conexion.ObtenerConexion();
    using SqlCommand cmd = new("dbo.SP_ListarMatriculas", cn)
    {
        CommandType = CommandType.StoredProcedure // <-- CERO SQL EN TEXTO PLANO
    };

    cmd.Parameters.Add("@IdAnio", SqlDbType.Int).Value = idAnio;
    cmd.Parameters.Add("@IdSeccion", SqlDbType.Int).Value = idSeccion;
    cmd.Parameters.Add("@Filtro", SqlDbType.NVarChar, 100).Value = filtro?.Trim() ?? string.Empty;

    await cn.OpenAsync();
    using SqlDataReader dr = await cmd.ExecuteReaderAsync();

    while (await dr.ReadAsync())
    {
        MatriculaEntity matricula = new();
        matricula.AsignarId(Convert.ToInt32(dr["IdMatricula"]));

        // Leemos el estado del estudiante devuelto por el SP
        string estadoEstudiante = dr["EstadoEstudiante"] != DBNull.Value 
            ? dr["EstadoEstudiante"].ToString() 
            : "Activo";

        matricula.AsignarEstudiante(
            Convert.ToInt32(dr["IdEstudiante"]),
            dr["CodigoEstudiante"].ToString(),
            dr["NombreEstudiante"].ToString(),
            estadoEstudiante
        );

        matricula.AsignarAnioSeccion(
            Convert.ToInt32(dr["IdAnio"]),
            dr["NombreAnio"].ToString(),
            dr["Ciclo"] != DBNull.Value ? dr["Ciclo"].ToString() : string.Empty,
            Convert.ToInt32(dr["IdSeccion"]),
            dr["NombreSeccion"].ToString()
        );

        matricula.AsignarDetalles(
            Convert.ToDateTime(dr["FechaMatricula"]),
            dr["EstadoMatricula"].ToString(),
            dr["DocenteGuia"].ToString(),
            dr["Aula"].ToString(),
            estadoEstudiante
        );

        lista.Add(matricula);
    }

    return lista;
}
C# — MatriculaDal.cs (MatricularSiguienteAnioAsync) 
public async Task<(int NuevoIdMatricula, string Mensaje)> MatricularSiguienteAnioAsync(int idMatriculaActual, int idSeccionNueva)
{
    using SqlConnection cn = Conexion.ObtenerConexion();
    using SqlCommand cmd = new("dbo.SP_MatricularSiguienteAnio", cn)
    {
        CommandType = CommandType.StoredProcedure
    };

    cmd.Parameters.Add("@IdMatriculaActual", SqlDbType.Int).Value = idMatriculaActual;
    cmd.Parameters.Add("@IdSeccionNueva", SqlDbType.Int).Value = idSeccionNueva;

    // Parámetros de salida (OUTPUT)
    SqlParameter paramNuevoId = new("@NuevoIdMatricula", SqlDbType.Int) { Direction = ParameterDirection.Output };
    SqlParameter paramMensaje = new("@MensajeResultado", SqlDbType.NVarChar, 200) { Direction = ParameterDirection.Output };
    cmd.Parameters.Add(paramNuevoId);
    cmd.Parameters.Add(paramMensaje);

    await cn.OpenAsync();
    await cmd.ExecuteNonQueryAsync();

    int nuevoId = (paramNuevoId.Value != DBNull.Value) ? Convert.ToInt32(paramNuevoId.Value) : 0;
    string mensaje = paramMensaje.Value?.ToString() ?? "Operación completada.";

    return (nuevoId, mensaje);
}
🧠 5. Capa de Lógica de Negocio (`MatriculaBll.cs`)
🎙️ Lo que le dices al profesor sobre la BLL:
"En `MatriculaBll.cs` está el cerebro del software. Es la capa que aplica las políticas del Ministerio de Educación y del colegio: valida si un estudiante está retirado (Inactivo), calcula si con el 50% de cada semestre pasa la materia con al menos 60 puntos, verifica si acumuló 3 materias a reparación (en cuyo caso repite el año completo), y si aprobó todo, lo promueve o gradúa."
C# — MatriculaBll.cs (EvaluarPromocionEstudiante) 
public EvaluacionPromocionModel EvaluarPromocionEstudiante(MatriculaEntity matricula, List<CalificacionEntity> calificaciones)
{
    var evaluacion = new EvaluacionPromocionModel
    {
        IdMatricula = matricula.IdMatricula,
        IdEstudiante = matricula.IdEstudiante,
        CodigoEstudiante = matricula.CodigoEstudiante,
        NombreEstudiante = matricula.NombreEstudiante,
        IdAnioActual = matricula.IdAnio,
        NombreAnioActual = matricula.NombreAnio,
        EstadoActualMatricula = matricula.EstadoMatricula,
        EstadoEstudiante = matricula.EstadoEstudiante
    };

    // =========================================================================
    // REGLA 0: VALIDACIÓN DE ESTUDIANTE INACTIVO (DADO DE BAJA / EXPULSADO)
    // =========================================================================
    if (matricula.EstadoEstudiante.Equals("Inactivo", StringComparison.OrdinalIgnoreCase))
    {
        evaluacion.EsInactivo = true;
        evaluacion.PuedeAvanzar = false;
        evaluacion.DebeRepetir = false;
        evaluacion.Dictamen = "ATENCIÓN: El estudiante se encuentra en estado INACTIVO. Debe reactivarlo en Alumnos antes de matricularlo.";
        return evaluacion;
    }

    // =========================================================================
    // REGLA 1: VALIDACIÓN DE NO DUPLICIDAD DE PROMOCIÓN O REPETICIÓN
    // =========================================================================
    if (matricula.EstadoMatricula.Equals("Promovido", StringComparison.OrdinalIgnoreCase))
    {
        evaluacion.YaFueAprobado = true;
        evaluacion.Dictamen = "ATENCIÓN: El estudiante ya ha sido APROBADO y PROMOVIDO anteriormente a este grado.";
        return evaluacion;
    }
    if (matricula.EstadoMatricula.Equals("Repite Año", StringComparison.OrdinalIgnoreCase))
    {
        evaluacion.YaFueReprobado = true;
        evaluacion.Dictamen = "ATENCIÓN: El estudiante ya fue registrado anteriormente como repitente.";
        return evaluacion;
    }

    // =========================================================================
    // REGLA 2: EVALUACIÓN DE MATERIAS Y CALIFICACIONES (50% Semestre I + 50% Semestre II)
    // =========================================================================
    int aprobadas = 0, enReparacion = 0, reprobadas = 0, enProceso = 0;
    decimal sumaFinales = 0;

    foreach (var cal in calificaciones)
    {
        cal.CalcularResultado(); // 0.50 * SemestreI + 0.50 * SemestreII
        if (cal.NotaFinal.HasValue)
        {
            decimal nota = cal.NotaReparacion.HasValue ? cal.NotaReparacion.Value : cal.NotaFinal.Value;
            sumaFinales += nota;
        }

        switch (cal.EstadoAsignatura.Trim().ToLower())
        {
            case "aprobada": aprobadas++; break;
            case "reparación": enReparacion++; break;
            case "reprobada": reprobadas++; break;
            default: enProceso++; break;
        }
    }

    // Regla Institucional: 3 o más clases a reparar -> Repite Año
    if ((enReparacion + reprobadas) >= 3)
    {
        evaluacion.DebeRepetir = true;
        evaluacion.Dictamen = $"Reprobó/Dejó a reparación {enReparacion + reprobadas} asignaturas (Máximo permitido: 2). Debe repetir el año escolar.";
        return evaluacion;
    }

    // Regla: 100% de asignaturas aprobadas
    if (aprobadas == calificaciones.Count && calificaciones.Count > 0)
    {
        if (matricula.IdAnio == 5) // 11mo Grado / 5to Año
        {
            evaluacion.EsGraduado = true;
            evaluacion.Dictamen = "¡Felicidades, estudiante graduado! Ha completado exitosamente su bachillerato.";
        }
        else
        {
            evaluacion.PuedeAvanzar = true;
            evaluacion.Dictamen = $"Todas las asignaturas aprobadas (Promedio: {evaluacion.PromedioFinal:N2}). Apto para matricularse en {evaluacion.SiguienteAnioNombre}.";
        }
    }

    return evaluacion;
}

private void ActualizarBadgeEstadoEstudiante(string estadoEstudiante, string estadoMatricula)
{
    string est = estadoEstudiante?.Trim().ToLower() ?? "activo";
    string mat = estadoMatricula?.Trim().ToLower() ?? "activo";

    // 1. PRIORIDAD MÁXIMA: Si el alumno está dado de baja, siempre se marca INACTIVO
    if (est == "inactivo")
    {
        lblBadgeEstadoEstudiante.Text = "INACTIVO";
        lblBadgeEstadoEstudiante.BackColor = Color.FromArgb(254, 226, 226); // Rojo suave
        lblBadgeEstadoEstudiante.ForeColor = Color.FromArgb(153, 27, 27);  // Rojo oscuro
    }
    else if (mat == "estudiante graduado" || est == "estudiante graduado")
    {
        lblBadgeEstadoEstudiante.Text = "ESTUDIANTE GRADUADO";
        lblBadgeEstadoEstudiante.BackColor = Color.FromArgb(254, 243, 199); // Ámbar dorado
        lblBadgeEstadoEstudiante.ForeColor = Color.FromArgb(146, 64, 14);
    }
    else if (mat == "promovido")
    {
        lblBadgeEstadoEstudiante.Text = "APROBADO / PROMOVIDO";
        lblBadgeEstadoEstudiante.BackColor = Color.FromArgb(219, 234, 254); // Azul suave
        lblBadgeEstadoEstudiante.ForeColor = Color.FromArgb(30, 64, 175);
    }
    else if (mat == "repite año" || mat == "repite ano")
    {
        lblBadgeEstadoEstudiante.Text = "REPROBADO / REPITE AÑO";
        lblBadgeEstadoEstudiante.BackColor = Color.FromArgb(254, 226, 226); // Rojo
        lblBadgeEstadoEstudiante.ForeColor = Color.FromArgb(153, 27, 27);
    }
    else
    {
        lblBadgeEstadoEstudiante.Text = "ACTIVO (CURSANDO)";
        lblBadgeEstadoEstudiante.BackColor = Color.FromArgb(220, 252, 231); // Verde suave
        lblBadgeEstadoEstudiante.ForeColor = Color.FromArgb(22, 101, 52);   // Verde oscuro
    }
}

❓ Pregunta Clave: "¿Por qué crearon un procedimiento almacenado en vez de hacerlo en C#?"
Tu respuesta: "Por tres motivos fundamentales, profesor: 1) Seguridad: elimina el riesgo de Inyección SQL. 2) Rendimiento: SQL Server compila y memoriza el plan de ejecución del SP en memoria. 3) Atomicidad: Usamos BEGIN TRANSACTION / COMMIT / ROLLBACK para que, si falla la inserción de materias, no quede la matrícula a medias."
❓ Pregunta Clave: "¿Cómo evitaron que un alumno aparezca en dos grados a la vez al ser promovido?"
Tu respuesta: "En el procedimiento SP_ListarMatriculas aplicamos una CTE con ROW_NUMBER() OVER (PARTITION BY IdEstudiante ORDER BY IdMatricula DESC) AS Fila. Al filtrar con WHERE Fila = 1, el sistema solo toma la matrícula activa más reciente, garantizando que el alumno no se duplique."
